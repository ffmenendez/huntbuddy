You
Which process on FIN-LT-0442 talked to 185.220.101.4, and under which account?

      
Assistant

        
Filter outgoing network events to that host and remote IP. actor_process_image_name is the process that opened the socket. actor_effective_username is the account it ran as.

        
// Illustrative example. ENUM.NETWORK is untested.
config timeframe = 24h
| dataset = xdr_data
| filter event_type = ENUM.NETWORK
    and agent_hostname = "FIN-LT-0442"
    and action_remote_ip = "185.220.101.4"
    and action_network_is_server = false
| fields _time, actor_process_image_name,
    actor_effective_username,
    causality_actor_process_image_name

        
Add causality_actor_process_image_name to see what launched it, for example outlook.exe → powershell.exe.
